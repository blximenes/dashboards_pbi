# 📊 Dashboard - Análise de Uroculturas

Dashboard desenvolvido em Power BI para análise de resultados de exames laboratoriais, utilizado como apoio ao Trabalho de Conclusão de Curso (TCC) e posteriormente publicado como artigo científico.

## Tecnologias

- Power BI
- Power Query
- DAX
- Modelagem de Dados

## Funcionalidades

- Indicadores de positividade
- Distribuição por sexo
- Distribuição por faixa etária
- Principais bactérias identificadas
- Evolução temporal
- Filtros interativos
