# 📊 Análise de Uroculturas – Power BI

Projeto de análise e visualização de dados desenvolvido no **Power BI** a partir de dados utilizados em um artigo científico sobre a prevalência bacteriana em amostras de uroculturas no estado do Piauí.

Minha contribuição no projeto foi voltada à etapa de **dados e Business Intelligence**, incluindo o tratamento, organização, análise dos dados e desenvolvimento das visualizações utilizadas no estudo.

## 🎯 Objetivo

Transformar os dados de uroculturas em informações visuais que permitissem analisar a prevalência bacteriana e identificar padrões relacionados a sexo, faixa etária, agentes etiológicos e sazonalidade.

## 🛠️ Atividades desenvolvidas

- Tratamento e padronização dos dados com Power Query
- Organização e preparação da base para análise
- Modelagem dos dados no Power BI
- Criação de cálculos e indicadores utilizando DAX
- Desenvolvimento das visualizações
- Análise exploratória dos dados
- Construção do dashboard interativo

## 📊 Principais análises

- Frequência de uroculturas positivas e negativas
- Positividade por sexo
- Relação entre sexo e faixa etária
- Prevalência dos principais agentes bacterianos
- Comparação do perfil bacteriano entre os sexos
- Evolução mensal dos casos positivos

## 🚀 Tecnologias utilizadas

- Power BI
- Power Query
- DAX
- Modelagem de Dados
- Visualização de Dados

## 📈 Dados analisados

Foram analisadas **13.450 amostras de uroculturas**, referentes ao período de janeiro a dezembro de 2024.

## 🔬 Aplicação científica

As análises e visualizações desenvolvidas foram utilizadas no estudo:

**“Análise de prevalência bacteriana em amostras de urina de pacientes realizadas em um laboratório de referência do Estado do Piauí no período de janeiro a dezembro de 2024”.**

O estudo foi posteriormente publicado como artigo científico.
